# 김민욱 백엔드 개발자 포트폴리오

Java와 Spring Boot를 중심으로 진행한 프로젝트의 설계, 구현, 배포 경험을 정리한 포트폴리오입니다.

## 바로 보기

- [웹 포트폴리오](https://kr-uk.github.io/portfolio/)
- [PDF 포트폴리오](https://kr-uk.github.io/portfolio/portfolio-backend.pdf)
- [GitHub 프로필](https://github.com/kr-Uk)

## 주요 경험

- Spring Boot 기반 도메인·REST API 설계
- PostgreSQL, Redis, JPA, QueryDSL을 활용한 데이터 처리
- Docker, Nginx, GitLab CI/CD 기반 배포 환경 구성
- Prometheus, Grafana, Loki 기반 모니터링과 로그 수집

## 대표 프로젝트

- [DotShelf](https://github.com/kr-Uk/dotshelf) — 멀티플랫폼 독서 기록·가상 책장 서비스
- [Itto](https://github.com/kr-Uk/itto-backend) — 위치 기반 소셜 매칭 서비스
- [Bone To Be](https://github.com/kr-Uk/bone-to-be) — AI 골격 인식 기반 의류 추천·가상 착용 서비스
